Record what you actually observe.

Collect repeatable vegetation and site observations before calculating ecological outcomes. The form creates a local JSON or CSV file that you can archive and compare with later visits. It does not submit records to GitHub or a server.

Scientific limit: These are **sampled first-hit percentages**, not proven sitewide native cover, ecological integrity scores, measured soil infiltration, or ecosystem-dollar gains. This is an intentionally simplified protocol inspired by BLM guidance, not a full certified BLM AIM survey.

1. Site, plot and repeat-visit setup

2. Simplified first-hit sampling

Choose a fixed, documented set of points along your transect. At each point, count one first encountered class along a vertical pin/drop: native plant, introduced invasive, other introduced, litter, rock/crust, bare soil, or unknown. If you cannot reliably identify a plant as native or introduced, record unknown. These classes must be mutually exclusive. Count the same number of locations and use the same method at later visits.

This simplified top-hit protocol does not replace the BLM's full multi-layer species-level line-point intercept procedure. It supports repeatable **first-hit observations only** and must not be mixed analytically with differently collected visual-cover data.

3. Soil surface and management context

No soil compaction or infiltration values are calculated here. Use NRCS Field Book for Describing and Sampling Soils (2024) if collecting standardized soil observations.

4. Validate and export a visit

The preview divides each class's count by the total number of recorded first-hit points. No invented site area, benefit score, or monetary value is attached. Export one visit at a time and preserve the sample design for future comparisons.
